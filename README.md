# Minh Anh Portfolio

Portfolio cá nhân tĩnh dùng Bootstrap 5, Chart.js và Mermaid.js. Mở `index.html` để xem giao diện.

## Kích hoạt form email

1. Mở [script.google.com](https://script.google.com), tạo project mới và dán nội dung `Code.gs`.
2. Đổi `OWNER_EMAIL` trong `Code.gs` thành email nhận thông báo của bạn.
3. Chọn **Deploy > New deployment > Web app**, chạy với tư cách bạn và cho phép **Anyone** truy cập. Sao chép URL Web App.
4. Dán URL vào `APPS_SCRIPT_URL` trong `script.js`.

Khi người xem gửi form, Apps Script sẽ gửi email HTML cảm ơn đến họ và một bản thông báo đến chủ portfolio.
